# Mister Desk

Собственная доска задач для команды «Мистер-Мебель».

## Первая версия

- Доска Kanban с колонками «К выполнению», «В работе» и «Готово».
- Создание, редактирование и удаление задач.
- Приоритет, исполнитель, срок и описание.
- Поиск по задачам и фильтр по исполнителю.
- Перетаскивание карточек между колонками.
- Сохранение данных в браузере через `localStorage`.
- Адаптация для телефона и компьютера.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages в настройках репозитория (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).

> Сейчас это автономный MVP: данные сохраняются в браузере, где открыт сайт. Для совместной работы сотрудников понадобятся авторизация и серверная база данных.
